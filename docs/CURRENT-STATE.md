# Current state: the rules and decisions in force

Written 2026-10-08, the day MTG Compare was ported from OP Compare, against [DECISIONS.md](../DECISIONS.md) up to the entries of that day.

The short version of the log: what still stands. Each bullet ends with a link to its entry, labelled by date; [DECISIONS-INDEX.md](DECISIONS-INDEX.md) gives every entry by month. If this page and an entry disagree, the entry wins: fix the page. When a new entry changes or reverses a bullet, update the bullet in the same commit. `npm run decisions:index` fails if a link here no longer lands on its entry.

Entries dated before 2026-10-08 are OP Compare's inherited history (One Piece vocabulary, a daily release, a history branch, a Neon-backed catalogue). They explain why the rules of the port exist; where they disagree with a bullet below, the bullet is the port's decision.

## Deploys, builds and egress

- Preview and development builds are off; a preview builds only for a `[preview]` commit subject the owner asked for; production deploys weekly (Tuesday 08:00 UTC) or on `[deploy]` / a manual run when the owner says now. [2026-10-08](../DECISIONS.md#L2053)
- Production ships code once a week (Tuesday 08:00 UTC, `production-deploy.yml`, `RELEASE_CRON`); data is published daily and never needs a deploy; `[deploy]` is added to a commit subject only when the owner says a release is urgent. [2026-10-08](../DECISIONS.md#L2632)

## Reading the data: loaders, caches, files

- A build reads no data host, no data directory and no database: the plane reader throws `PlaneError("build")` while `NEXT_PHASE=phase-production-build` (HTTP and `PLANE_DIR` alike) and `src/lib/db.ts` targets a closed local port in that phase. [2026-10-08](../DECISIONS.md#L2263)
- Every plane read of a request is pinned to the commit the request's first `getDataRef()` returned (React request cache; the 20-second instance memo outside a request); instance memos of derived shapes are keyed by `memoKey(ptr)` (`ref:seq:publishedAt`). [2026-10-08](../DECISIONS.md#L2301)
- Pinned files are read from `pointer.repo` (the pointer itself from `PLANE_REPO`): a repository rotation changes the pointer only. [2026-10-08](../DECISIONS.md#L2314)
- `POST /api/data-warm { ref }` (Bearer CRON_SECRET) warms the named commit's hot set and is the only call a publish makes; `POST /api/revalidate` purges only `NEON_TAGS`; `GET /api/data-status` is the instance's pointer, host and memory in a body without secrets. [2026-10-08](../DECISIONS.md#L2321)

## Matching, stores and eBay

- The finish of a store listing is decided per variant (variant words and SKU suffix, then the title, then the store's explicit-foil convention); a Foil tag never decides; two products at one (set, number) that both sell the foil and a title with no treatment word is a skip. [2026-10-08](../DECISIONS.md#L2327)
- A store listing matches ONE (product, finish) or nothing: the key is the SKU, then SET-NUM in the title, then number + set name, then name + set; a name alone is never a key; the name, set and treatment gates run before the finish step and an ambiguous listing is skipped (`src/lib/match.ts`, `tests/match.test.ts`). [2026-10-08](../DECISIONS.md#L2334)
- A store's own spelling of a set resolves only through `STORE_SET_ALIASES` (`src/lib/match.ts`), an entry needs three SKU-consistent listings and a pinned real title; the matcher reads no file and no database. [2026-10-08](../DECISIONS.md#L2355)
- A free-text (eBay) title that names The List is placed on The List's product (set `plst`, number `<set>-<number>`) or on nothing, never on the original printing it reprints. [2026-10-08](../DECISIONS.md#L2361)

## Pages and tools

- Taxonomy hubs read the browse engine (`getCardPage`, `getFacetCounts`); /cards/treatment/[key] replaces /cards/printing/[printing]; a colour page is exact (gold cards only on /colors/multicolor). [2026-10-08](../DECISIONS.md#L2375)
- Box EV uses only Wizards-published slot structures (Play Booster); a slot without a published split is valued at zero until the visitor sets a rate; no pull rate is invented. [2026-10-08](../DECISIONS.md#L2383)
- Sealed pages and the sealed alert read published files only; MSRPs are listed only with a source and check date, and none are invented. [2026-10-08](../DECISIONS.md#L2389)
- Commander pages read the ORACLE_FLAGS.COMMANDER bit from the published files; the deck pages are force-dynamic and priced at read time. [2026-10-08](../DECISIONS.md#L2438)
- outbound clicks are logged anonymously (`ClickEvent`, userId null) through `/api/click`, batched into one insert in the half-hour window shared with the view counter, swept after 90 days; `CLICK_LOG=0` turns it off. [2026-10-08](../DECISIONS.md#L2456)
- Consent Mode v2 defaults come from `consentDefaultsScript` (src/lib/ga.ts), rendered once by `<ConsentDefaults />` ahead of every Google tag; the footer's privacy settings link re-opens the choice. [2026-10-08](../DECISIONS.md#L2463)
- the home reads `hm/home.json`, `mk/overview.json` and `mk/records.json` through `src/lib/data/home.ts`; Popular is the EDHREC rank; the page is force-dynamic with no revalidate. [2026-10-08](../DECISIONS.md#L2469)
- the sitemap is the index `/sitemap.xml` plus `/sitemaps/<kind>-<n>.xml` handlers (force-dynamic, `publicDataHeaders`, at most 10,000 URLs each, counts from `sm/plan.json`, lastmod = the pointer's `priceDay`); there is no `sitemap.ts`, and IndexNow follows the index. [2026-10-08](../DECISIONS.md#L2495)
- Editorial posts read only the bounded loaders in `src/lib/blog/context.ts`; no post, page or share image calls `getCatalog()`. [2026-10-08](../DECISIONS.md#L2528)
- The Fan Content sentence and the unofficial-fan-site notice exist once, in `src/lib/site.ts`; About, Terms and the footer import them. [2026-10-08](../DECISIONS.md#L2536)
- robots.ts blocks GPTBot, CCBot, Google-Extended and Bytespider; search/answer crawlers are allowed. [2026-10-08](../DECISIONS.md#L2610)

## Decks and Commander

- a pasted deck line resolves, in order, to the exact product (`#id`), the printing (set + collector number), the cheapest regular printing among those of the set it names, or the CHEAP printing of the card; its finish is the line's (`*F*`/`*E*`), else Normal, else the only finish it has. [2026-10-08](../DECISIONS.md#L2396)
- no module under `src/lib/deck*.ts` or `published-decks*.ts` holds or loads the catalogue; lists are resolved line by line through the loaders (`resolveDeckLines`). [2026-10-08](../DECISIONS.md#L2411)
- deck rules are `DECK_FORMATS` in `src/lib/commander-rules.ts` (pure); a format whose size is `verified: false` is not size-checked; unknown legality is judged as nothing. [2026-10-08](../DECISIONS.md#L2432)
